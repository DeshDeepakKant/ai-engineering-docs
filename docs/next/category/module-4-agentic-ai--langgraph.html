Module 4: Agentic AI & LangGraph

ReAct pattern, StateGraph, cyclic workflows, database checkpointers, human-in-the-loop approvals, subgraphs, SQL agents, CrewAI, and Smolagents.

📄️01. Agentic AI Fundamentals

Understand how autonomous AI agents work, master the ReAct (Reason + Act) cognitive loop, and compare chains vs agents.

📄️02. LangGraph Core Concepts

Master LangGraph's core primitives: TypedDict state schemas, node functions, normal edges, and conditional routing edges.

📄️03. Graph Execution Patterns

Construct sophisticated multi-node topologies: linear sequences, fan-out/fan-in parallel execution, and dynamic routing.

📄️04. State Persistence & Checkpointers

Persist agent graph states across reboots, manage threads, and inspect conversation state snapshots.

📄️05. Streaming in LangGraph

Stream LLM tokens and intermediate graph state updates to user interfaces using stream_mode='values' and 'messages'.

📄️06. Human-in-the-Loop (HITL)

Implement approval gates and breakpoints in LangGraph to allow human verification before executing sensitive actions.

📄️07. Multi-Agent Subgraphs

Structure large agent systems into hierarchical specialist subgraphs managed by a supervisor router agent.

📄️08. Database SQL Agents

Build an enterprise Text-to-SQL database agent with schema introspection, query validation, and safe query execution.

📄️09. CrewAI Multi-Agent Collaboration

Orchestrate role-playing autonomous agents using CrewAI: Agents, Tasks, Tools, and Sequential/Hierarchical Processes.

📄️10. Smolagents & Agno (Phidata)

Explore cutting-edge lightweight agentic frameworks: HuggingFace Smolagents (Code Agents) and Agno high-performance multi-modal agents.
