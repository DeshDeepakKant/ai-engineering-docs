Module 5: Model Context Protocol (MCP) & Claude Code

Model Context Protocol (MCP) architecture, local and remote servers, MCP clients, Claude Code CLI, CLAUDE.md spec-driven development, Plan Mode, and custom subagents.

📄️01. MCP Protocol & Architecture

Understand Anthropic's open standard that solves the N x M integration problem between AI clients and enterprise data sources.

📄️02. MCP Lifecycle & Transports

Deep dive into the 3-phase MCP handshake: Initialization, Operation, and Shutdown across stdio and SSE transports.

📄️03. Building Local MCP Servers

Build, test, and register your own custom Python MCP server using FastMCP to expose tools and resources to Claude Code.

📄️04. Remote MCP Servers & Deployment

Deploy scalable, remote MCP servers over HTTP with Server-Sent Events (SSE) using Docker and FastAPI.

📄️05. Building Custom MCP Clients

Build an MCP client in Python: connect to MCP servers, list tools dynamically, and bind them to LangChain agents.

📄️06. Getting Started with Claude Code

Install Claude Code CLI, configure terminal environments, authenticate via Anthropic Console, and understand its core architecture.

📄️07. Claude Code Workflow & Slash Commands

Master essential slash commands (/help, /compact, /cost, /clear) and prevent context window exhaustion.

📄️08. Spec-Driven Dev & CLAUDE.md

Stop 'vibe coding': establish rigid architecture boundaries, coding standards, and deterministic test commands using CLAUDE.md.

📄️09. Plan Mode & Custom Skills

Use Plan Mode (Shift+Tab) for strategic architectural planning and write custom reusable Skills using SKILL.md.

📄️10. Subagents, Hooks & Plugins

Scale context windows with specialized Subagents, configure automated lifecycle Hooks, and install community Plugins.
