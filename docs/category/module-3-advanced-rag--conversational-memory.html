Version: v2.0 (Clean & Unified Master)

Module 3: Advanced RAG & Conversational Memory

Document loaders, semantic chunking, vector stores (FAISS/Chroma), Hybrid Search (BM25), Corrective RAG (CRAG), Self-RAG, Multimodal RAG, and memory persistence.

📄️01. RAG Architecture & Fundamentals

Understand why foundation models require RAG, compare fine-tuning vs RAG, and master the two-phase lifecycle.

📄️02. Document Loaders

Ingest unstructured data from PDF files, web pages, and YouTube video transcripts into clean LangChain Documents.

📄️03. Text Splitters & Chunking

Master chunk size, chunk overlap, and why RecursiveCharacterTextSplitter is the industry standard for RAG.

📄️04. Vector Embeddings & Vector Stores

Convert text chunks into dense numerical vectors and store them in high-speed vector databases like FAISS and Chroma.

📄️05. Retrievers & Hybrid Search

Combine dense semantic vector search with sparse keyword search (BM25) using reciprocal rank fusion for superior recall.

📄️06. End-to-End RAG Pipeline

Construct a complete, production-ready RAG application combining PDF ingestion, Chroma DB, LCEL, and citation formatting.

📄️07. Corrective RAG (CRAG)

Evaluate document relevance with an automated grader node and trigger web search fallback when internal docs are insufficient.

📄️08. Self-Reflective RAG

Equip language models with introspection: determine when to retrieve, evaluate factual grounding, and detect hallucinations.

📄️09. Multi-Modal RAG

Ingest complex technical documents containing architecture diagrams, flowcharts, and financial tables using Multi-Vector Indexing.

📄️10. Conversational Memory & Persistence

Manage multi-turn conversational context, prevent context window overflow, and persist chat history across sessions using SQLite.
