Module 2: LangChain Mastery & Local LLMs

LCEL declarative chains, Runnables, Chat Models, Prompts, Structured Outputs, Ollama local models, and Guardrails. Unified from CampusX & Krish Naik.

📄️01. LangChain Architecture & Setup

Understand the decoupled architecture of modern LangChain: langchain-core, community, and partner provider packages.

📄️02. Chat Models & Providers

Switch between proprietary and open-source models seamlessly using LangChain's unified BaseChatModel interface.

📄️03. Prompts & Prompt Templates

Construct dynamic, reusable prompt templates, manage conversational roles, and teach LLMs via few-shot examples.

📄️04. Structured Outputs & Parsers

Force LLMs to return strict, typed Pydantic objects instead of unpredictable unstructured strings.

📄️05. LCEL & The Runnable Protocol

Compose declarative pipelines using the Unix pipe (|) operator with built-in streaming, batching, and async support.

📄️06. Advanced Runnables Composition

Master advanced LCEL primitives: RunnablePassthrough, RunnableParallel, and RunnableLambda for multi-branch workflows.

📄️07. Local LLMs with Ollama

Run powerful open-weight models (Llama 3, Gemma 2, DeepSeek) completely locally and offline using Ollama and LangChain.

📄️08. Streaming LangChain with FastAPI

Deploy LCEL runnables into production FastAPI microservices using Server-Sent Events (SSE) for low-latency token streaming.

📄️09. Tools & Tool Calling

Equip LLMs with real-world capabilities: define Python functions with @tool and bind them to chat models.

📄️10. Guardrails & Safety

Protect your applications against prompt injections, toxic content, and PII leakage using validation guardrails.
