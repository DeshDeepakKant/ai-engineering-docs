## 💡 Concept & Architecture

The agentic AI landscape in 2026 is evolving rapidly. Two prominent modern frameworks have emerged:

### 1. HuggingFace Smolagents: The Code Agent Revolution
Traditional agents communicate with tools via JSON:
- `ToolCall: calculate_interest({"p": 1000, "r": 0.05, "t": 10})`
For complex operations requiring loops, conditionals, or data transformations, JSON tool calling is clumsy. 

**Smolagents** introduces **Code Agents**:
Instead of outputting JSON, the model directly writes executable Python snippets! Writing native code allows the agent to create loops, store intermediate variables, and compose complex logic in a single turn.

### 2. Agno (formerly Phidata)
Agno is an ultra-fast, multi-modal agent framework optimized for real-time video, audio, and financial data processing with built-in memory and storage.

### Part 2: Step 2: Building a Code Agent with Smolagents

```python
# Blueprint demonstrating Smolagents CodeAgent
from smolagents import CodeAgent, HfApiModel, tool

@tool
def get_stock_history(ticker: str) -> str:
    """
    Fetches historical pricing for a ticker.
    Args:
        ticker: The stock ticker symbol (e.g. 'NVDA')
    """
    return f"Simulated pricing for {ticker}: 2024: $490, 2025: $980, 2026: $1450"

# CodeAgent writes and runs safe Python code directly in a secure sandbox
# agent = CodeAgent(tools=[get_stock_history], model=HfApiModel())
# response = agent.run("Calculate the percentage growth of NVDA between 2024 and 2026.")

print("Smolagents Code Agent blueprint initialized.")
print("The agent composes native Python code to solve math and tool pipelines in one turn.")
```

#### 🔍 In-Depth Explanation:
Instead of issuing 3 separate JSON tool calls, the model writes a 3-line Python script that calls the tool, computes the percentage difference, and returns the answer.

## ⚠️ Beginner Tips & Best Practices

:::tip Use Sandboxed Execution for Code Agents
Never run code generated by an LLM with raw `exec()` without security sandboxing. Smolagents includes an internal restricted AST interpreter that forbids importing dangerous modules like `os` or `subprocess`.
:::

:::warning Framework Churn
The open-source AI agent ecosystem evolves rapidly. Always prioritize understanding fundamental state machine concepts (LangGraph) over framework-specific syntax.
:::
